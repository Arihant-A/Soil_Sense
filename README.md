# Soil_Sense
A microcontroller-based IoT project using ESP8266 and a soil moisture sensor to automate plant watering. It activates a water pump when soil dries out, visualizes moisture data online, and leverages Open-Meteo API for weather-aware irrigation—enabling water-efficient, low-maintenance plant care. 

It is a smart agricultural tool developed to monitor the soil moisture level and automate the irrigation process. This project eliminates the need for manual watering hecks and introduces a more efficient, automated plant care system that can be highly beneficial in home gardening, smart farming, and sustainable agriculture.

This project aims to:

• Automate the detection of soil moisture levels using sensor technology.

• Ensure timely irrigation by activating water pumps when soil is dry.

• Conserve water resources by reducing unnecessary watering.

• Support sustainable agriculture and smart gardening practices through automation.

• Send data to website visualizing the graph of how the soil is watered.

• Predicts humidity and rainfall data in advance using the OPENMETEO API, which helps us plan and start the water supply accordingly.
